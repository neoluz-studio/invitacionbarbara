# Invitación XV editable

Abrí la carpeta con Visual Studio Code y ejecutá `index.html` con Live Server.

## Edición rápida
- Textos, fecha, alias, links y WhatsApp: `js/config.js`
- Fotos: reemplazá los archivos de `assets/images/` manteniendo los nombres. Podés usar JPG, pero actualizá las extensiones en `config.js`.
- Música: colocá un MP3 en `assets/audio/musica.mp3`.
- Estilos: `css/styles.css`

La página es mobile-first y responde en celulares, tablets y escritorio. Los SVG incluidos son marcadores propios y deben reemplazarse por fotos del evento.
